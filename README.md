# Creche Escola Futurinho

Landing page da Creche Escola Futurinho — Tijuca, Rio de Janeiro.

- Site em produção: https://creche-futurinho.vercel.app
- Deploys automáticos a cada push nesta branch (`master`), via integração Vercel + GitHub.

## Estrutura

- `index.html` / `script.js` — site estático completo
- `assets/depoimento-foto.jpg` — foto real do Instagram usada na seção de depoimentos
- `design-source/Futurinho.dc.html` — arquivo original do Claude Design (referência)
